# ClipFlow 0.5.0 开发预览

适用于Apple Silicon Mac，最低声明macOS14；当前实测macOS27.0.1。临时签名，未Apple公证。完整安装、首次“仍要打开”和辅助功能授权说明见仓库docs/INSTALL.md，DMG内也附有HTML和文本说明。

## 本次更新

- Command+X剪切与复制均收录到历史，实际剪切删除与入库已验证。
- 可选钉钉图片自动补全：设置中开启后，下载所复制钉钉图文里的图片并保存，单图提供PNG，混排提供RTFD/HTML。新安装默认关闭，可对旧记录手动补全。此选项会联网访问HTTPS钉钉图片链接，不读取浏览器Cookie或凭据。
- 菜单精简，其他操作移入设置；菜单记录选择后尝试直接粘贴，并将所选记录保留供后续Command+V。
- 图片文件复制保留图像字节，解决部分图片粘贴为文件名的问题。
- 原固定置顶改为“移到第1条”，后续新复制继续进入最前面。

## 测试与边界

71项测试、16个套件通过，2次真实SIGKILL及3次重开检查通过。真实钉钉三图样本转换、持久化及原生富文本接收通过；安装版历史复制后实际粘贴收到3图，重复Command+V共6图。原历史迁移逐项校验通过。固定0.5授权后12键注册成功，菜单选择已知文本自动粘贴到Target、随后Command+V继续同内容的路径通过。

完整12键、连续高速、多软件兼容与复杂原文排版仍待实测。菜单自动直贴需要权限与正确焦点，其目标消费不由“事件已发布”证明。钉钉/微信/Word等目标编辑器需支持内嵌HTML或RTFD；纯文本输入框无法显示图片。临时图片链接过期需重新复制。

下载DMG和SHA256SUMS.txt，核对后把App拖入Applications；不要把Source code压缩包当作安装包。更新前退出App。临时签名变化时需移除旧辅助功能条目、添加当前副本。不要关闭Gatekeeper或SIP。
