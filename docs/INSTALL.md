# ClipFlow 安装与首次使用

## 1. 下载安装包

普通用户不需要安装 Xcode、Swift 或使用终端编译。

1. 打开 https://github.com/lrc839-tech/ClipFlow/releases 。
2. 在 Assets 中下载 `ClipFlow-版本号-macOS-arm64.dmg`，不要把自动生成的 Source code 压缩包当成安装包。
3. 双击 DMG，在打开的磁盘窗口中把 `ClipFlow.app` 拖到 `Applications`（应用程序）文件夹。
4. 从 Mac 的“应用程序”文件夹打开 ClipFlow，不要直接从 DMG 中运行。安装后可以推出该磁盘映像。

本安装包仅适用于 Apple Silicon Mac（M 系列芯片），不是 Intel 或 Windows 安装包。当前仅在 macOS 27.0.1 / Apple Silicon 验证；程序声明最低 macOS 14，其他系统版本尚未完成验收。

## 2. 首次打开：未公证应用的系统提示

当前是0.6.0开发预览版，使用临时签名，尚未经过 Apple Developer ID 签名和公证。请确认安装包来自上面的项目 Releases，并阅读版本说明。

如果系统提示“无法验证开发者”或“Apple 无法检查是否包含恶意软件”：

1. 先尝试从“应用程序”打开 ClipFlow，出现拦截提示后关闭提示；不要选择把应用移到废纸篓。
2. 打开“系统设置 → 隐私与安全性”，向下找到“安全性”区域中刚被阻止的 ClipFlow。
3. 核对应用名后，点击“仍要打开 / Open Anyway”。如系统要求，由你本人输入 Mac 密码或使用 Touch ID。
4. 系统再次弹出确认框时，点击“打开 / Open”。以后通常可以直接双击打开。

不要求反复双击固定次数：关键是先触发一次系统拦截，再到设置中确认。如果设置中没有对应提示，可重新尝试打开一次，再返回设置查看；受管理的 Mac 可能需要联系管理员。

这只是允许该应用运行，不等于已经获得跨应用输入权限，下一步仍需授权。

Apple 官方说明：https://support.apple.com/zh-cn/102445 。如果提示“将损坏你的电脑”或应用“已损坏”，请停止安装，重新从项目 Releases 下载并核对 SHA-256，联系项目维护者；不要把所有安全提示都当成普通未公证提示。无需关闭 Gatekeeper、关闭 SIP 或执行移除隔离属性的命令。

## 3. 允许跨应用粘贴

1. 打开“系统设置 → 隐私与安全性 → 辅助功能”；部分系统显示“设备控制和数据访问”。
2. 点击“+”，添加安装到“应用程序”文件夹的 `ClipFlow.app`，并启用开关。不要添加 DMG 内的副本。
3. 退出 ClipFlow 再重新打开，或点击历史页顶部“重试注册”。
4. 确认历史页显示“输入权限已就绪”和“Command接管中：12/12”。

如果注册失败，先退出使用相同全局快捷键的其他工具，再重试；也可以切换“Option回退”。“仍要打开”与辅助功能授权是两个不同的步骤。

## 4. 日常使用

- 正常使用 Command+C 复制或 Command+X 剪切内容，ClipFlow 自动收录历史。
- 也可以在目标应用的输入框中，从 CF 菜单点选某条历史直接粘贴。所选内容留在系统剪贴板，随后 Command+V 继续粘贴它。用户另行复制新内容时，以新复制为准。
- 先点击目标应用的输入框，再按 Command+1～9、0、-、=，粘贴当前第1～12槽记录。槽位以历史页面显示为准。
- 点击菜单中的“设置”进入历史页，可以搜索、预览、复制和移到第1条。“移到第1条”把选中记录放进快捷键1，其他记录往下顺移。后续新复制会排在它前面。粘贴保持顺序。
- Command 模式会占用浏览器切标签、缩放等同组合功能。用历史页的“释放全部快捷键”、按应用排除或“Option回退”调整。系统保留组合和安全输入等情形仍有边界。
- 关闭设置窗口后继续在菜单栏常驻。点 CF → 设置可重新进入历史和设置，展开“更多设置与诊断”可调整粘贴方式、等待时间、查看存储或退出。
- Markdown 保留来源提供的源码；图片和文件的粘贴取决于目标应用支持。常见图片文件会保存图像字节，其他文件保留引用，移动或删除源文件后相关旧记录可能失效。旧版仅存引用的图片需要原文件仍可访问才能补读。

图片历史在CF菜单和设置页直接显示缩略图。菜单点选仍为粘贴；设置页点缩略图或“预览”，可在右侧查看图片，再点图片放大。图文记录最多展开前12张本地附件。预览只读取本机已保存数据，不会为预览访问远程图片链接。

首次测试请使用空白测试文档或测试输入区，不要在正式发送、支付或密码输入框中测试。

### 钉钉图文变成实际图片

在 CF → 设置 → 更多设置与诊断中开启“自动补全图片”（新安装默认关闭）。复制或剪切钉钉文档图文后，等待历史行显示“已保存N张图片”，再选择该历史粘贴。只有一张图片且没有文字时按图片提供；带文字或多图时按RTFD/HTML图文提供，目标软件需要支持对应格式。补全不主动覆盖当前剪贴板，完成后需用ClipFlow选择记录。也可对已有记录点击“补全钉钉图片”。

此功能会联网访问复制内容里的HTTPS钉钉图片地址，保存到本机历史；不读取浏览器Cookie或登录凭据。链接过期或需要登录时，请回钉钉重新复制。最多12张、单张下载8MiB，保留原始内容，失败可重试。不会抓取任意网站图片；并非所有目标编辑器都能接受内嵌HTML/RTFD，建议先在空白草稿测试，不发送消息。

## 5. 更新、排障与卸载

更新前退出正在运行的 ClipFlow；用新版本替换原安装位置的 App，避免同时保留并运行多份。历史保存在用户资料目录，替换 App 不会主动清空历史。

临时签名可能随版本变化。若授权开关已经开启但 App 仍显示未授权：先退出 ClipFlow，在辅助功能列表中移除旧 ClipFlow 条目，再添加并启用当前安装副本，随后重开。此步骤需要你手动完成。

卸载时先退出应用，再移除 App。历史目录 `~/Library/Application Support/ClipFlow/` 默认保留；其中可能含敏感剪贴板内容，请自行备份和管理。不要把历史数据库或原始诊断文件上传到公开 Issue。

## 6. 当前限制

本版本是开发预览，不是已完成全部验收的稳定版。完整Command12键、持续高速粘贴、Edge冲突与释放、Finder双文件实际复制、混合格式队列、系统重启和其他系统版本仍待分别验收。事件已发布不等于目标应用已完成消费，没有“所有软件无条件最高优先级”保证。
