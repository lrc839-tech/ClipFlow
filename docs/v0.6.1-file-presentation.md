# 0.6.1 文件类型与授权入口修复

2026-11-11。

## 修改

- CF菜单授权状态行改为可点击的“打开授权”入口，使用已有系统辅助功能设置链接。输入权限是否开启仍由系统决定。
- 修复Finder复制文件时附带的`com.apple.icns`被当作图片的问题。文件引用优先决定语义：PPT、Word、Excel、PDF等保持文件；JPG、PNG等实际图片文件继续显示缩略图。
- 对文件记录，菜单、设置列表和预览区展示文件名及系统类型小图标；不把文件图标或附带PNG/TIFF缩略表示当成正文图片。图标根据类型获取，源文件失效时仍可显示文件名和类型，复制失效引用则仍会明确报错。
- 文件出站保留文件引用，移除同一文件项目附带的图像表示，避免目标应用优先把文件图标当图片。图片文件仍可物化为图像粘贴；多文件保持引用顺序。
- 旧历史按实际文件引用重新计算显示类型，不重写原始记录、内容指纹或排序。

文件类型图标使用[Apple NSWorkspace.icon(for:)](https://developer.apple.com/documentation/appkit/nsworkspace/icon(for:))，不抓取网络图标。

## 验证

- 80项测试、18个套件通过。新增5项覆盖ICNS/PNG/TIFF附带图标的文档分类与具名剪贴板文件引用读取、旧历史类型/文件名/筛选、文件不产生图片预览、真正PNG图片缩略图与图片粘贴、多文件/旧文件名列表和失效源文件的类型图标。
- 2次真实SIGKILL、3次重开检查通过，提交前后持久化恢复保持。
- 隔离界面使用同一份HTML和系统真实PPT/Word类型图标：三条混合记录只有一条显示图片缩略图，另外两条分别显示文件名和28px类型图标。PPT/Word预览区没有大图；切回图片时文件信息清空，图片可放大并关闭。控制台无错误和警告。
- 最终安装版对实际曾被误判的PPT记录检查：列表与预览区均显示文件名称和PowerPoint小图标，没有作为大图展示。
- 运行时菜单对象确认授权状态项可用并绑定授权入口，文件项带类型图标。状态行实际点击和系统授权结果仍需手工确认，不以菜单对象的可点击标记代替实际跳转证据。
- 更新前备份264条历史与旧App；更新后264条身份与内容指纹全部保留。263条原元数据完全一致，另1条在备份后复制时间和排序发生更新，另外新增1条复制记录；没有为展示修复重写历史。
