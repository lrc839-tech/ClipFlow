# 0.6.3 当前剪贴板异常阻断历史粘贴

2026-11-24，本机修复版，尚未发布到 GitHub Releases。

## 根因与修改

旧版全局快捷键在发布所选历史前，强制使用历史收录的严格规则备份当前系统剪贴板。当前剪贴板出现 `org.nspasteboard.TransientType`，或者声明文本格式但未提供数据时，备份失败直接中止历史粘贴。实际按键已经进入回调，不是注册状态能够证明或解决的问题。重启0.6.2后仍复现。

0.6.3的系统剪贴板粘贴路径直接用选中历史替换当前剪贴板，粘贴后保留该历史供Command+V继续使用；不读取、备份或归档被替换的当前内容。短纯文本快速输入模式保持原实现。快照归档继续拒绝敏感/临时标记，不放宽收录规则。等待期间检测到用户新复制则保留新复制，不覆盖它。更换前台应用仍取消事件发送。

## 已验证

- 87项测试、19个套件通过。新增4项覆盖临时剪贴板、声明类型但数据不可读、期间新复制优先、富文本与图片多项目原始字节及顺序。
- 保留原有租约恢复行为作为默认API，现有恢复/并发写入测试继续通过；App全局快捷键显式选择不恢复旧剪贴板，菜单保留模式不再多余读取当前剪贴板。
- release构建及本机安装副本签名校验通过。安装前备份SQLite与记录身份，922条原有历史身份和内容指纹全部保留；数据结构及内容文件没有迁移。

## 待验收

0.6.3二进制签名已改变，需要重新添加当前安装副本的辅助功能权限。授权前不能把实际跨应用快捷键粘贴标为通过。授权后验证Command+1/2/3、菜单选择与后续Command+V，并在原来失败的软件核对接收。

本轮不在授权期间重新构建已固定安装副本。GitHub公开0.6.2仍是旧包，不能用于验证本补丁。
