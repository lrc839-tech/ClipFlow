# mac复制工具 0.7.0：开机自启、剪贴板同步与固定快捷键

2026-11-24，本机开发预览；公开Release仍是旧版0.6.2。

## 使用方式

- 应用名称改为“mac复制工具”，安装在 `~/Applications/mac复制工具.app`，菜单栏入口为“复制”。沿用原Bundle标识和本机数据目录，保留原历史与设置。
- 设置首页“登录 Mac 时自动启动”默认勾选，可取消。使用[SMAppService.mainApp](https://developer.apple.com/documentation/servicemanagement/smappservice)注册，显示系统实际结果；需要系统批准和操作失败均明确显示，不能把勾选等同于已注册。
- 快捷粘贴后Command+V使用所选内容；短纯文本快速输入先同步剪贴板，再发Unicode事件，保留快路径。期间若有新复制则保留新复制。0.6.3关于当前剪贴板异常阻断粘贴的修复一并保留。
- 历史行选择快捷键后点击“固定到所选快捷键”，可固定任意1～9、0、-、=槽位。固定槽不滚动，未固定槽由其余最新历史依次填充；固定记录不重复占用滚动槽。支持同一记录固定多个槽，替换已有绑定和解除固定。
- 设置顶部列出全部固定槽及解除按钮，菜单和历史行标注“📌固定”。配置以稳定记录ID保存，重开保留；删除历史时清除其绑定。历史原字节和排序没有因绑定而修改。

## 已验证

- 96项测试、21套件通过，覆盖固定槽滚动、稀疏槽位不改键号、重复绑定、重新绑定/解除/删除、持久化、原格式保持、自启默认开启、取消后重开、系统审批与错误状态。
- 真实原生WebKit设置窗口：默认自启开启、取消变为已关闭、重新启用变为已开启。更名后再次取消/启用成功，系统后台项目记录URL指向新安装路径，状态enabled/allowed。
- 实际设置页把自建QA文件记录固定到Command+9，出现固定状态；正常退出重开后绑定仍在；解除后回到无固定槽。测试绑定已撤销，不替用户选择固定内容。
- 实测发现并修正了固定槽整数键传入JSON诊断导致退出的问题；修复后的固定、重开和解除完整路径通过。
- 更新前备份929条历史身份、SQLite及偏好；安装后929条原记录ID与内容指纹均保留。测试过程中用户新增复制正常保留。
- 新名称的设置窗口、应用菜单和菜单栏标题已应用。安装副本签名校验通过，不在授权验收期间重建。

## 当前边界与下一步

- 内置浏览器预览连接超时，改用真实macOS原生WebKit窗口验证；未宣称隔离网页控制台检查或窄屏验证通过。
- 新二进制与新安装路径需要重新添加辅助功能授权。Command+3后Command+V、固定9/0/-/=真实跨应用粘贴尚待授权后手工测试，不能由注册状态或设置页测试替代。
- 自启注册/取消及系统记录已实测，注销或重启后真正自动启动仍需用户手工验收。系统登录项显示名称可能缓存旧名，实际路径已核对为新应用。
- 非图片文件仍为引用，源文件移动或删除可能失效；固定不会把文件复制成独立备份。
