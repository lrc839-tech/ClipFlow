## 行为

- 新设置默认选择 Command+1～9、0、-、=，对应当前置顶优先的12槽；启用状态、模式和排除列表跨重开保持。
- “释放全部快捷键”真正注销全局注册，独立于暂停历史监听；释放后继续收录历史。
- 可选Option回退。注册失败显示具体组合及返回码，不自动改键或强抢其他工具的已有注册。
- “按应用排除”：填写Bundle ID（每行一个），或把上次前台应用一键加入。前台变成排除应用时注销全部12键，切回未排除应用时恢复；不是仅忽略已被吞掉的事件。
- 输入权限未就绪时不注册、不占键。重新授权后重开或点“重试注册”。空槽在接管有效时仍占组合，只显示空槽提示。
- 改模式、释放、权限失效或前台变化后，旧排队粘贴失效；剪贴板发送前再次检查状态。已发出的粘贴不能撤回，恢复保护照常执行。
