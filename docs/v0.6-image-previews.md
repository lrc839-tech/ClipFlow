# 0.6 图片历史预览

2026-11-11，开发预览。

## 实际实现

- 设置页的图片历史直接显示缩略图；点击缩略图或“预览”，右侧展示图片，再点图片打开大图，支持关闭和Escape返回。
- CF菜单为有本地图片的历史记录显示等比例缩略图，最大72×48点；点击仍走原有的直接粘贴动作。图片异步准备完成后原位更新菜单项，不在菜单跟踪期间因缩略图重新排序条目。
- 支持保存的PNG/TIFF/JPEG等系统可读图像、仍可访问的旧本地图片引用，以及RTFD图文中的图片。已补全的钉钉图文可展开最多前12个图片附件。
- RTFD若对重复图片只保存一份文件，按正文中的本地附件引用保留预览顺序与重复出现。无法识别引用时退回本地附件列表，不执行HTML或读取远程链接。
- 后台ImageIO生成小图；独立预览缓存上限16MiB、96组，合并同一尺寸和内容的并发请求。记录索引读取与图像解码分开，解码不进入粘贴FIFO。预览不改原图数据、历史顺序或系统剪贴板。
- 数据已损坏、源文件已失效或图像像素超过解码上限时不伪造预览，页面给出不可用提示。删除后的记录不返回旧缓存图片。

RTFD文件包装格式按系统接口解析，参见[Apple FileWrapper说明](https://developer.apple.com/documentation/foundation/filewrapper/init(serializedrepresentation:))。

## 已测试

- 75项测试、17个套件通过，新增4项预览测试覆盖持久化原图缩略图与大图、重复RTFD附件、钉钉补全前后缓存更新、重开、旧本地图片引用、文件删除、普通文本和远程HTML不抓图、无效图片、历史删除后的缓存隔离。原有剪切、多格式、普通排序和粘贴租约回归保持通过。
- 隔离数据库2次真实SIGKILL、3次重开检查通过。
- 界面交互路径：历史列表缩略图 → 右侧多图 → 点击放大 → 关闭。使用与安装版相同HTML、独立本机数据夹和合成图片桥接，在内置浏览器的Playwright接口验证。页面标题/地址匹配，有3条混合记录且只有2条显示缩略图；展开为2图，大图可打开关闭，控制台无错误或警告。
- 默认桌面与窄窗口验证：窄窗口实际宽450px，无水平溢出，缩略图和放大窗口关闭按钮可见。请求360px时内置浏览器实际保持最小450px，因此不宣称已验证360px。
- 最终0.6已安装并验签。在原生设置页对本机实际图片点击缩略图，右侧出现图像，再次点击打开大图并可关闭。纯文本不出现图片占位。实际菜单对象加载3条图片缩略图，状态栏菜单的视觉呈现仍需用户点开确认。
- 更新前完整备份252条历史和旧App。安装后逐项校验这252条的身份、指纹、复制时间、排序与旧置顶字段未改变；用户在更新期间另有新复制，当前记录数相应增加，不覆盖它们。

预览采用本地已保存数据，没有因浏览器QA而上传私人历史或图片。界面测试的桥接是隔离的显示测试，不能替代原生App与系统剪贴板的完整验收。

## 待验证与下一阶段
