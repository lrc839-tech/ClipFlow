## 安装与首次打开

仅适用于 Apple Silicon（M系列）Mac；本版本使用临时签名，尚未经过 Apple 公证。

1. 下载 Assets 中的 `ClipFlow-0.6.2-macOS-arm64.dmg`，打开后将 ClipFlow.app 拖到 Applications，再从应用程序文件夹启动。
2. 如果被 macOS 拦截，先尝试打开一次，再到「系统设置 → 隐私与安全性」点击「仍要打开」，完成系统确认。无需反复双击固定次数。
3. 到「辅助功能／设备控制和数据访问」添加并启用实际安装的 ClipFlow。更新后若旧条目无效，先移除再重新添加，退出重开后检查快捷键状态。
4. DMG 内附中文安装说明，详见[安装与首次使用](https://github.com/lrc839-tech/ClipFlow/blob/main/docs/INSTALL.md)。
